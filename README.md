# 💼 Kunal Marwari | Personal Portfolio Website

A responsive and modern **personal portfolio website** created to showcase my profile, education, technical skills, projects, and contact information.

The website is designed with a clean dark-themed interface and provides an easy way for visitors and recruiters to learn about my background and explore my projects.

## 👨‍💻 About the Project

This project is my personal portfolio/resume website.

It presents my professional profile along with my educational background, technical skills, portfolio projects, and contact information in a single responsive website.

---

## ✨ Features

- 🎨 Modern dark-themed UI
- 📱 Responsive design
- 🧑‍💻 Personal profile section
- 🎓 Education timeline
- 🛠️ Technical skills section
- 📊 Animated-style skill progress bars
- 💼 Portfolio/project showcase
- 📧 Contact section
- 🔗 GitHub and LinkedIn profile links
- ✨ Hover animations and interactive effects
- 📱 Mobile-friendly layout
